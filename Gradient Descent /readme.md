This repository contains my implementation of Linear Regression using Gradient Descent from scratch, without relying on sklearn’s built-in optimizers.
The goal of this project is to deeply understand:
1. How Gradient Descent works internally
2. How coefficients are updated mathematically
3. The difference between Batch Gradient Descent and Stochastic Gradient Descent
4. How optimization behaves in both Simple and Multiple Linear Regression

This project includes custom-built classes for:
  Simple Linear Regression (Single feature)
  Multiple Linear Regression (Multiple features)
  Stochastic Gradient Descent (SGD)
  Custom evaluation and comparison methods
